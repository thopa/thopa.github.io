Network · Max for Live · 8 modulators · core 0.0.1

How Network moves

Network is eight small modulators that modulate each other while they move parameters in your Set. On its own an LFO repeats; in Network, one LFO's speed is pushed around by another one, which is pushed by a third, so the motion never quite repeats. You don't patch wires: each bank of four uses one of six fixed layouts, and you change the character by switching layouts and turning depths. Everything below runs the device's real modulation engine. Switch the sound on and turn things.

EXAMPLESload one, then change it

01THE NETWORKwho moves whom

Two banks of four nodes: A1–A4 and B1–B4. Each bank has its own layout, a fixed set of wires from one node to another node's rate, amp, shape, phase or clock. A wire's strength is its source node's depth. Couple wires the two banks together (A4 → B1 rate, B4 → A1 rate), and Feedback sends each bank's first node back into its own rate. Wires glow with the value they carry; click a node to edit it.

TrySwitch bank A from Chain to Ring: now A4 pushes A1 again, the loop closes, and the motion stops repeating. Then raise Feedback A.

02NODES→ the wires, the outputs

Every node is one of four types and has the same controls: rate, amp, and two dials, A and B, whose meaning depends on the type. LFO: A morphs sine → triangle → saw → square. Loop env: an envelope that retriggers itself; A is how much of the cycle it rises, B the curve. S&H: a new random value every cycle (or on the layout's clock); A is slew, B quantises to steps. Geiger: random clicks at an average rate; A is the click width, B how regular they are. SYNC nodes follow the song position, FREE nodes run in Hz.

TrySelect A2 and make it a Geiger at 1/8 with regularity 0: the chain now gets random kicks. Set A3 to S&H with steps up: the pan jumps between fixed positions.

03OUTPUTS→ parameters in your Set

In the device each node's output maps to a Live parameter, like any Max for Live modulator, and a node can drive a group of up to three parameters at once (its lanes 1–3), some of them inverted. Here the targets are the controls of a small synth. Pick the node that drives each one, how far it moves (negative = inverted) and where it rests. Two or more targets with the same node make a group; turn on hand-off (pass) in that node (section 02) and it moves one target at a time, handing over each cycle while the others hold.

TryDrive Cutoff, Resonance and Drive from the same node, with Resonance at −50 %: the filter opens while the resonance falls back, the way the mockup's node E does.

04RHYTHM→ MIDI notes

A rule compares two nodes and plays a note while it is true. a > b plays when a rises above b; a and b when both are high; a crosses b on every crossing. b can also be a fixed threshold. The modulation becomes a drum pattern that drifts with it.

TrySwitch rule 1 on with A1 > A2: kicks land where the two LFOs cross over, and move as A1's rate is pushed around.

05PITCH→ MIDI notes

One node becomes a melody: on every tick its value is read, spread over the range and fitted to the scale. The tick is a clock division or another node's trigger, so a Geiger can play it. Prob thins both the rhythm and the pitch notes; the modulation itself never skips.

TrySource A1, tick 1/8, minor pentatonic. Then put A2 on A1's rate (Chain): the melody speeds up and slows down by itself.

A simulation for learning: the page runs the generated Network core (the same code as the device's gen~ engine, at 1 kHz instead of audio rate) and a small Web Audio synth in place of your Set. The device itself is not built yet; this is core 0.0.1, so names, defaults and the accent colour may change. In the device the outputs move Live parameters (modulating around the knob in Live 12, taking it over in Live 11), patterns store everything here, and the rhythm and pitch notes go out as MIDI. Settings here aren't saved.
